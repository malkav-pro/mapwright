**Gathered:** 2026-09-23

<domain>
## Phase Boundary

Close DOC-01's coordinate-system amendment before Phase 2. New and imported maps have a 1,000-map-unit longest edge with aspect-scaled shorter edge. Editing and export pixel resolutions are independent samplings of that geometry. Preserve visual and durable behavior of Phase 1 projects.

</domain>

<decisions>
## Implementation Decisions

### Document coordinates
- **D-01:** Map geometry has top-left origin, x right, y down, double-precision CPU coordinates, exactly 1,000 units on its longest edge and aspect-scaled shorter edge.
- **D-02:** Initial grid counts establish aspect ratio and starting Grid only; later grid spacing does not resize map geometry. Grid UI remains Phase 4.
- **D-03:** Imported raster pixel dimensions establish aspect and initial editing sampling, not map extents. Keep source dimensions/provenance and an explicit source-to-map transform.

### Independent resolution and units
- **D-04:** Editing resolution is fixed at creation/import in P0; export resolution is independent. Longest-edge preset contracts are 1K/2K/3K/4K editing and 1K/2K/3K/4K/8K/16K export, K = 1,024 pixels. Preset selection UI and advanced export controls remain Phase 4.
- **D-05:** Brush diameters, river geometry and future map-relative sizes use map units. UI handles/markers stay in screen pixels. Zoom or output resolution cannot change committed geometric sizes.

### Compatibility and preservation
- **D-06:** Existing Phase 1 pixel-space project data must not be silently reinterpreted. Test migration or explicit safe legacy handling, including retained editable commands and reopen/history behavior.
- **D-07:** Preserve fixed Background/Foreground terrain, single Foreground mask, river semantics, bounded rendering, export cancellation/atomic publication and Phase 1 durability.

### Acceptance examples
- **D-08:** A 4:3 map is 1,000 × 750 units for both 40 × 30 and 80 × 60 initial grids and for 1K or 4K editing sampling.
- **D-09:** A 7,559 × 8,192 imported raster maps to 922.7294921875 × 1,000 units with no preview stretch.
- **D-10:** A 96-map-unit brush retains the same relative map size and placement at 1K and 4K output; automated tests cover import, gestures, persistence/history and viewport/export alignment.

### the agent's Discretion
- Internal type and schema design, migration mechanism, test fixture design, and whether existing projects migrate eagerly or on first open, provided D-06 is satisfied.

</decisions>
