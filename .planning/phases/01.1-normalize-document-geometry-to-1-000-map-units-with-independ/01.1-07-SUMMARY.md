# Phase 01.1 Plan 07: GPU Terrain Tracer Summary

**A real-map global-device compute tracer produced pixel-correct acknowledged legacy strokes, but the measured mixed-run p95 was 57.825 ms, so R1 is halted.**

## Outcome

The tracer consumes a CPU-prepared immutable flattened RGBA8 source, computes each durable 60-sample legacy texture stroke on Godot 4.7.2's global Vulkan RenderingDevice, and draws a revision/generation-tagged display RID through `MapCanvas`. The endpoint is the matching `_Draw` followed by `FramePostDraw`, not dispatch recording. The ordinary CPU canvas remains the default. `Scripts/App/Main.cs` also routes the existing ImportBounds and ConnectedTracer acceptance artifacts through the R0 run-root resolver; Phase 1 defaults are preserved.

The measured three-commit range from `plan_head_before` to the summary-writing HEAD contains one Plan 07 code commit (`209e6be`) and two interleaved Plan 06 follow-up commits (`41a86d8`, `a183bc5`) on the shared branch. The Plan 07-specific production change is one commit; the measured range is reported without hiding concurrent work.

The 63.154-second replay produced 15 acknowledged, individually correlated revisions at 827×896 on the pinned real map and AMD RX 7800 XT. Revisions 2–15 were 16.571–16.803 ms input-to-visible. Revision 1 was 57.825 ms; the 15-sample mixed p95 was therefore 57.825 ms, above the unchanged 50 ms gate. One frame exceeded 33.3 ms. Off-clock validation read back the final GPU frame: 257,565 pixels changed from the source and zero channels differed from the independent CPU reference by more than one level (maximum difference one). An earlier single-stroke trial took 55.806 ms, and a later separate one-stroke smoke took 68.689 ms; neither overwrote the 15-stroke evidence.

The first input timestamp **excluded** CPU flattened-base evaluation and global-device source/shader initialization. The first generation is not a valid full cold-state row, even though it missed 50 ms. Warm/first-generation samples in this trial must not be reclassified as 15 cold or evicted samples.

Raw evidence: `artifacts/gpu-terrain-tracer/trial-5f2a5e99c03f4df89905b5a7738e342f/gpu-terrain-tracer.json` and its `sequences.json`. The later smoke is under `trial-9bb2e2aa11b14deca5d59a7ae15b08e6`. These artifact roots were created uniquely and not overwritten.

## Deviations and findings

- [Rule 3 - Blocking] Fresh checkouts had no imported `.glsl` resource, so the tracer compiles the checked-in shader source directly on the global device and rejects compile errors. The first run exposed this on pinned Godot 4.7.2.
- [Rule 1 - Bug] Retiring output textures before later uniform sets caused invalid-RID errors on replay. Device resources now retire in reverse dependency order; a subsequent smoke exited without invalid-RID errors. This is not yet a queued-draw retirement proof.
- TDD gate was not satisfied: Plan 07 marks both tasks `tdd="true"`, but exploratory GPU code was committed without a prior intentional RED assertion/evidence commit. This violation is recorded, not represented as compliance.

## Deferred issues and next gate

R1 should remain halted until the full required modern coverage, cold/evicted/strict, hard-edge precision and resource lifecycle workloads are implemented and measured. The mixed 15-stroke replay already misses 50 ms on its first preinitialized-source revision; no workload, endpoint or percentile threshold was relaxed. A later architecture revision may revisit the cold path, but must preserve this counterexample and the CPU fallback.
