## Pattern Assignments

### Domain geometry and model

**Apply to:** `src/Mapwright.Domain/Geometry.cs`, `src/Mapwright.Domain/MapModel.cs`. **Analog:** those same files.

`Geometry.cs:3-9` establishes immutable double coordinates and finite validation:

```csharp
public readonly record struct MapPoint(double X, double Y)
{
    public void ValidateFinite()
    {
        if (!double.IsFinite(X) || !double.IsFinite(Y))
            throw new ArgumentOutOfRangeException(nameof(MapPoint), "Document coordinates must be finite.");
    }
}
```

`Geometry.cs:48-81` provides the existing sampling contract. Extend its geometry factory/size policy rather than giving renderers a separate coordinate formula:

```csharp
public readonly record struct DocumentRasterTransform(
    double DocumentWidth, double DocumentHeight, int OutputWidth, int OutputHeight)
{
    public MapPoint OutputPixelCenterToDocument(int outputX, int outputY)
    {
        Validate();
        return new MapPoint(
            (outputX + 0.5) * DocumentWidth / OutputWidth,
            (outputY + 0.5) * DocumentHeight / OutputHeight);
    }
}
```

The excerpt omits existing range checks at lines 68-69; retain them. `MapModel.cs:53-65` uses `ImportedRasterTransform(OffsetX, OffsetY, ScaleX, ScaleY)` with finite/positive scale validation. `MapModel.cs:899-909` stores double Width/Height and `StorageFormatVersion = 2`; `MapModel.cs:949-970` validates version, fixed Background/Foreground identities, river target and imported source. Extend version-aware geometry validation there; keep stable layer IDs and role invariants.

### Canvas, renderer and export

**Apply to:** `Scripts/App/MapCanvas.cs`, `Scripts/Rendering/ConnectedTerrainGraph.cs`, `Scripts/Export/DocumentPngExport.cs`.

`MapCanvas.cs:220-245` computes current viewport tile size from `ImportedSource.PreviewWidth/PreviewHeight`, then calls `EvaluateRegionAtSize` per tile. Replace the preview-derived size with persisted editing sampling. `MapCanvas.cs:848-859` maps pointer pixels to document coordinates via `imagePosition / textureSize * project.Width/Height`. `MapCanvas.cs:619-638` maps a document-space brush diameter to screen pixels for the scope cue; keep cue pixels screen fixed while geometry stays in map units.

`ConnectedTerrainGraph.cs:115-140` validates the snapshot and requested region, accounts for output/source/decoded bytes, then gets input rasters. `ConnectedTerrainGraph.cs:623-646` computes document positions at pixel centers and evaluates texture, Land and river there:

Use `DocumentRasterTransform` for the shared pixel-center mapping. `ConnectedTerrainGraph.cs:188-256` currently allocates background/foreground/coverage arrays proportional to the full canvas; a 16K export must avoid that full-size input cache. Its current resampling also fills the whole canvas from source rasters, so imported offset/scale placement needs explicit handling.

`DocumentPngExport.cs:612-660` enforces 16,384 dimensions, creates a `.partial` destination, captures an immutable revision, and fits bounded tile bands. `DocumentPngExport.cs:840-905` freezes the graph but currently evaluates a preview frame and nearest-neighbor scales it in `GraphFrozenRenderer.RenderAsync`; target-size export must sample editable geometry at requested pixel centers while retaining cancellation, blob pinning and atomic publication.

## Shared Patterns

- **Validation:** `Geometry.cs:54-63` rejects nonfinite/nonpositive geometry and output sizes; `MapModel.cs:949-970` enforces version, terrain and river invariants. Apply at creation, import, open and rendering boundaries.
- **Durability:** `SqliteProjectRepository.cs:343-369` uses parameterized SQL and one transaction for coupled revision/history updates. Migrate baseline, retained commands and version atomically.
- **Revision identity:** `DocumentPngExport.cs:645-648` rejects a captured renderer whose project/revision differs from the requested snapshot. Keep this for target-scale render capture.
- **Resource limits:** `ConnectedTerrainGraph.cs:124-132` uses checked byte arithmetic and resource admission; `DocumentPngExport.cs:652-660` fits output bands. Retain bounded accounting when source sampling becomes tile scoped.
