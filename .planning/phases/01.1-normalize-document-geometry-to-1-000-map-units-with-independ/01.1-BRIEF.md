# Phase 1.1 brief: Stable map units

## Outcome

Close the DOC-01 coordinate-system amendment before Phase 2 adds stamps and other map-relative objects. The longest geometric edge of each map is exactly 1,000 map units; the shorter edge follows the source or creation aspect ratio. Coordinates and sizes are double precision on the CPU, origin at top left, x right, y down. Editing/display raster pixels and export pixels are sampling choices, not geometry.

## Locked decisions and scope

- Imported raster dimensions establish aspect ratio and an initial editing resolution, but do not become document geometry. Retain source dimensions and an explicit source-to-map transform for alignment and provenance.
- Initial grid counts establish aspect and starting grid geometry; changing spacing later does not resize the map. The Grid UI itself remains Phase 4.
- Brush diameters, river points/width/softness, and future stamp, path, label, scatter and effect distances are in map units. Screen-space markers and handles stay in screen pixels.
- Editing resolution is fixed at creation/import for P0 and independent of export resolution. The approved longest-edge presets are 1K, 2K, 3K and 4K for editing, and 1K, 2K, 3K, 4K, 8K and 16K for export, where K means 1,024 pixels. Selection UI and extended export controls remain Phase 4; Phase 1.1 must establish the data and rendering contracts without inventing premature UI.
- Existing Phase 1 project data written with pixel-sized document geometry must not be silently reinterpreted. Provide tested migration or explicit legacy handling, preserving visual placement and durable history/reopen behavior.
- Preserve the fixed Background/Foreground terrain model, Phase 1 mask/river semantics, bounded rendering, export cancellation and atomic publication.

## Acceptance

1. A 4:3 map is 1,000 × 750 map units regardless of 40 × 30 versus 80 × 60 initial grid counts or 1K versus 4K editing pixels.
2. An imported 7,559 × 8,192 source becomes a 922.7294921875 × 1,000 map-unit geometry (allow a tight floating-point tolerance), with a source-to-map transform and no stretched preview.
3. A 96-map-unit brush remains 96 map units after changing viewport zoom, editing sampling or export preset. Equivalent strokes render at the same relative map position and size at 1K and 4K outputs.
4. An existing pixel-space saved project reopens with the same apparent geometry and retained editable commands, or explicitly refuses migration with a safe, actionable result; no silent reshape.
5. Automated tests cover import, gestures, persisted reopen/history and viewport/export alignment at multiple resolutions. Phase 1 acceptance contracts remain applicable.
