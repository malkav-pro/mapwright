# Phase 01.1 Plan 04: Target-Sampled Rendering and Export Summary

**Placed source rasters and editable map geometry now render at target pixel centers; frozen PNG export evaluates the selected resolution instead of enlarging a preview.**

## Accomplishments

- Bumped renderer tile compatibility to version 3. Normalized projects sample imported rasters through each stored map-unit offset and scale, clipping outside the footprint. Source-native decoding and tile buffers are admitted against the resource ledger before allocation; immutable decoded rasters are cached only while the ledger permits.
- Kept texture, Land, and river evaluation in the same global map coordinates and linear-premultiplied composition at tile seams. Reference contracts exercise a non-square, partially placed source, transparent gaps, reordered adjacent tiles, a 96-unit Land brush at 1K and 4K, and a 16K tile request.
- Changed graph export capture to retain the exact snapshot and pinned source blobs. Each requested tile is evaluated at final output dimensions, with cancellation and revision checks. The map-facing preset path derives the short edge with midpoint-to-even rounding and accepts only the six specified longest-edge counts.
- Extended the real export publication case to compare decoded 1K and 4K PNG pixels against graph samples, while preserving cancellation, failure cleanup, PNG validation, and atomic publication assertions. A 16K longest-edge tile is admitted; Plan 05 owns the full hardware 16K/resource matrix.

**1. [Rule 1 - Bug] Clamp bilinear edge samples before interpolation**
- **Found during:** Task 1
- **Issue:** A sample just inside a placed raster edge could blend its first and second intrinsic pixels after the integer coordinate was clamped.
- **Fix:** Clamp floating source coordinates before computing bilinear neighbors and fractions.
- **Files modified:** `Scripts/Rendering/ConnectedTerrainGraph.cs`
- **Commit:** `d57b948`

**2. [Rule 2 - Missing Critical] Pin derived display source and verify cached raster dimensions**
- **Found during:** Task 2
- **Issue:** A derived display blob was omitted from the frozen lease, and a reused hash cache entry did not recheck expected provenance dimensions.
- **Fix:** Include display blobs in the pin set and reject cached dimensions that disagree with the immutable source description.
- **Files modified:** `Scripts/Export/DocumentPngExport.cs`, `Scripts/Rendering/ConnectedTerrainGraph.cs`
- **Commit:** `a966839`

**3. [Rule 1 - Bug] Recheck cache admission for each requested tile**
- **Found during:** Final resource review
- **Issue:** A native source retained for a small tile could be reused for a larger tile without admitting the combined cache and tile bytes.
- **Fix:** Recheck the ledger on cache hits; evict and decode the source without retaining it when the larger tile would exceed the combined envelope.
- **Files modified:** `Scripts/Rendering/ConnectedTerrainGraph.cs`
