States and their exact copy
17 states · each with where it appears, what it says and the next action
S1Empty library
P2-01

"Nothing in the library yet. Install a pack, or import PNG and WebP files and give them a category."

Next: Install a pack… or Import images…, both focusable, the first focused.
S2Empty search
P2-01

"Nothing matches 'pine · conifer · winter'. 612 trees are in the library; three filters are narrowing them."

Next: Clear tags or Clear all filters. The filters stay visible so the cause is readable, not guessed at.
S3Thumbnails loading
P2-01, P2-03

Per tile: a spinner and "Loading…". Footer: "4 thumbnails building".

Next: none needed. Scrolling, filtering, selecting and placing all work. Nothing waits for the grid to finish.
S4Missing thumbnail
P2-01

"No thumbnail. The asset is here and places normally."

Next: none. A cache state — not S5. The two are drawn differently on purpose.
S5Original file missing
P2-01, P2-02

"The stored bytes for this asset are gone from the library. It cannot be placed. Projects already using it keep their own copy and are unaffected."

Next: Re-import the file, or remove the library entry. Placement is disabled with that reason on the button.
S6Duplicate asset
P2-03

"Already in the library as 'Highland pine, mature' — same stored bytes. This file reuses that asset rather than adding a second copy."

Next: Show it. No decision is required; the import proceeds either way.
S7Validation warning
P2-01, P2-02, P2-03

"41% of this image is transparent border. Added, with a badge." · "A dark offset lobe suggests a baked shadow. Mapwright renders shadows; a baked one will double."

Next: Inspect, Dismiss, or nothing. Never blocks use and never asks for acknowledgement.
S8Oversized decode rejected
P2-03

"panorama-ridge.webp is 16,384 × 11,264 — 184 Mpx, over the 64 Mpx per-file limit. Not added."

Next: resize it outside Mapwright and import again. The limit is named, so the fix is knowable.
S9Damaged file
P2-03

"oak-broadleaf-h.png could not be decoded past row 1,842 of 2,048. Not added."

Next: replace the file. A partial decode is never accepted — it would place with a torn edge and look like a rendering fault.
S10Bad pack manifest
P2-03

"This pack's manifest names schema mapwright.pack/4. This build reads up to 2. Nothing was imported." · malformed JSON gives the line and column.

Next: Import the files as loose images, which states what is lost — no stable local IDs, no declared metadata.
S11Import cancelled
P2-03

"Import cancelled. 114 of 184 assets were added and are usable. Re-importing the pack adds the remaining 70 and skips these."

Next: Resume import or carry on. Nothing is rolled back; every added asset is whole.
S12Missing original art
P2-04, on the map

Map, on hover or selection: "Mountain range, wide". Report: "9 instances · ink:mtn-range-03 · geometry preserved, artwork unresolved."

Next: Replace…. The command bar carries a running count so it is never only discoverable by hovering.
S13Replacement completed
P2-04

"9 instances now use 'Highland ridge, wide'. Each kept its own position, size, rotation and appearance. 6 source ids still unresolved."

Next: Undo (one step, named "Replace art — 9 instances"), or continue down the list.
S14No selection
P2-05, P2-06

"Nothing selected. Click a stamp on the map, or a row in the order list."

Next: the Placement settings panel stays fully live above it — there is always something to do.
S15One selected · mixed multi-selection
P2-05, P2-06

One: exact values, header "1 on the map". Several: header "3 selected", differing fields read Mixed with the actual values beneath, plus Scale by and Move by for relative change.

Next: absolute entry sets all; relative entry keeps the spread. Mixed is never shown as 0 or as a blank.
S16Hidden or locked target layer
P2-05, P2-06, P2-07

"Terrain marks is hidden. A stamp placed here would not be visible." · "…is locked. Locking is how you protect finished work." · marquee: "3 of 4 selected. ridge-peak-c is on a locked layer and was left out."

Next: Show layer / Unlock layer, explicitly. The canvas shows a refusal cursor and places nothing meanwhile.
S17Unsaved placement · save failure
status bar, everywhere

Pending: "Autosave queued · 3 commands", amber. Failed: "Save failed — the disk is full. 3 commands are not yet durable. Editing continues; do not rely on these edits surviving a restart."

Next: Retry save, Save as… elsewhere. The chip is never green while work is queued.
Rules these seventeen follow
1

Every state names the limit or the cause. "184 Mpx over the 64 Mpx limit", not "the file is too large". A number makes the fix knowable.

2

Every disabled control carries its reason where it sits, in text, not only in a tooltip — a tooltip is unreachable by keyboard.

3

Every state has a next action that is focusable, or says plainly that none is needed.

4

A catalogue problem never blocks the map. S1–S11 leave editing fully responsive; none of them is modal over the canvas.

5

Rejection and warning are visually distinct. Red for refused, amber for worth a look, neutral grey for a cache state. S4 and S5 read alike in words and must not look alike.

6

Nothing here suggests a network. No "syncing", no cloud glyph, no retry-with-connection language. Hashing and decoding are local work and are named as such.

7

A destructive scope is stated before it runs, with a count — "Replace 9 instances", never "Replace all".

8

Library refresh keeps your place. Scroll position, grid selection, map selection and viewport are untouched by a background rescan.

Which of these create a document undo step
Document commands — in history, undoable
Place a stamp · transform, tint, flip, opacity or shadow on a selection · reorder · duplicate · paste · delete · replace missing art (one step per scope) · commit a scatter stroke (one step per stroke) · re-roll a committed group · add, remove, reorder, rename, hide, lock, solo or re-opacity a layer · clear a layer's contents
Catalogue and tool operations — no undo step
Install or cancel a pack import · rename, retag, refile or recategorise an asset · change an asset's default size or anchor · dismiss a validation warning · re-run checks · change placement settings · change scatter controls or the pending seed · remember a replacement mapping · search, filter, scroll or select in the browser

The split is the reason the two panel groups are labelled. A catalogue change is durable but lives in the shared library, outside any project's revision history, so Ctrl+Z after renaming an asset undoes the last map edit — which would be a nasty surprise if the panels did not say which is which. Undoing a map edit likewise never reverts a rename.
