If the manifest cannot be read

"This pack's manifest names schema mapwright.pack/4. This build reads up to 2. Nothing was imported." — or, for malformed JSON, the line and column. Neither offers a partial import: a pack with an unreadable manifest has no stable local IDs, so importing its files would produce assets that a later correct install cannot reconcile. Importing the same files as loose images stays available, and says what is lost by doing so.

Master files are not touched
