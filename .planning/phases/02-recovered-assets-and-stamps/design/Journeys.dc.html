J5 Marquee, adjust the selection, scale in place, rotate the arrangement, duplicate

Scale by 130%

Rotate 18°

J6 Paint a forest, commit once, reopen and find it unchanged
P2-07 · STMP-03
Build the set

Four assets, two families and some low scrub. Not one stamp and not a whole category.

Set the ranges

Size 78–118% on, rotation −22°–22° on — each switched independently. Three assets clamp to ±15° and the panel names them.

Spacing 51 map units

Average centre-to-centre in map units. Zoom in and out: the number and the result do not change.

Drag across the slope

Ghosted stamps follow the brush, the count climbing. Esc would discard all of it; nothing is in history yet.

Release — one command

142 resolved placements, each with its asset, position, scale and angle written down. One row in the order list, one undo step. They are ordinary stamps now.

Save, reopen, move one, export

Identical placements. Zooming, a thumbnail refresh, undo and redo, selecting part of the group, and a future algorithm change all leave them where they are. Only Re-roll moves them, and it says how many first.
