Three numbers called "size", never in the same panel. The tags above each one appear on the panel header itself, so a glance at the header answers the question before any field is touched. A fourth possibility — editing an asset's default and having placed stamps follow — is not offered at all: a placement records its own size, and the library cannot reach into a project's history.

Every tool keeps its own settings
Tool Size Its own remembered settings Target

Texture brush B 31 map units preset, tip, hardness, flow, spacing, texture transform Foreground or Background
Land L 125 map units variant, roughness or softness, add or subtract Foreground's land mask
Text T — Phase 3 its own size, never the stamp's or the brush's the selected object layer

Switching Stamp → Texture brush → Stamp leaves 408 px at 408 and 256 at 256. No tool's size, or any other parameter, is ever adopted by another. The one thing that does carry is within the Stamp tool: choosing another asset keeps the settings above. Changing the Texture brush's terrain target likewise keeps that tool's settings.

The protected object layer

Every map starts with one object layer beside Grid, Foreground and Background, so there is never a moment where the Stamp tool has nowhere to aim and asks you to create something first. Additional object layers can be added and reordered freely, with no count cap.

OBJ Objects
Disabled, with the reason on hover and in the panel: "The last object layer cannot be deleted. Clear its contents instead."

Clearing its 418 objects is an ordinary undoable command. Deleting the layer itself is not offered, rather than offered and then refused.
